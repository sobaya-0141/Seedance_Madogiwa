# そば屋カードデザイン案

`imagegen`のbuilt-in tool modeで生成した、カードUI検討用のラスターモックアップ。
ゲーム組み込み用の完成素材ではなく、フレーム・情報階層・質感の方向性を比較する
ためのコンセプト画像。

## 共通プロンプト

- 用途: プレミアムなトレーディングカードゲームのカードデザイン
- 参照画像: `02_CHARACTERS/Sobaya.jpg`
- 必須要素: 白い仮面、黒い眼孔、縦の赤模様、短い黒髪、白い半袖Tシャツ、
  筋肉質な体格、大型ビールジョッキ
- 表示テキスト: `そば屋` / `4` / `窓際の店主` / `快適です！`
- 構成: 正面向きの縦2:3カード、上部に人物、下部に能力と方向パターン
- 禁止: 仮面の変更、ジョッキの省略、武器や防具、透かし、複数カード

## A — Obsidian Gold Champion

黒漆とアンティークゴールドを基調にした王道TCG案。エンボス、金属製パワー章、
控えめな虹色ホログラムで、印刷物としての高級感を優先。

## B — Neon Grid Holographic

ミッドナイトネイビー、シアン、マゼンタのデジタルTCG案。角形フレーム、
半透明ガラス、回路状の陣地線、強いホログラムでゲーム画面との親和性を優先。

## C — Modern Izakaya Heritage

紺の暖簾、赤提灯、和紙、金箔を使った現代的な立ち飲み処案。花札的な構図を
取り入れつつ、能力欄は現代TCGとして読みやすく整理。

## D — Editorial Titanium Minimal

チタン、白、黒、仮面の赤を使ったミニマル案。スイスデザイン風のグリッド、
大きな数字、余白、限定的なパールホログラムでモバイル視認性を優先。
