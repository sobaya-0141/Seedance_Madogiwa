# そば屋の会社ブレイカー ～3D物理解体～

大型ビールジョッキを投げ、10投以内に無人のモックオフィスを連鎖崩壊させる
フル3D物理解体アクションです。建物は約120〜230個の独立した剛体で構成され、
柱を抜くと上階が自重で傾き、壁同士の衝突が次の破壊を呼びます。

世界観上はアクシデンチュア株式会社公認の解体演習です。建物はDIYのハリボテで、
中は無人。人的被害や暗い会社描写のないカートゥーン物理で、最後は跡地に
立ち飲み処を建てる明るい騒動として扱います。

## 遊び方

1. 壊したい場所をタップ／クリックして照準を固定する
2. POWERゲージのタイミングを見て、もう一度タップ／クリックすると投擲
3. 放物線プレビューを使い、柱の根元や梁の接合部を狙う
4. 10投以内にCOMPANY INTEGRITYを赤いクリアライン以下まで落とす

キーボードでは矢印キーで照準移動、`Space`で照準固定／投擲、`1`と`2`で
ジョッキを切り替え、`C`でカメラ切り替え、`Esc`で狙い直せます。

投擲後はカメラがジョッキを追尾し、衝突時はスローモーションと接写へ移行します。

## ジョッキ

- 通常ジョッキ: 何度でも使用可能。高いPOWERほど爆風とダメージが上昇
- 超乾杯ジョッキ: 各ステージ1回。広い範囲へ強い衝撃を与え、鉄骨にも有効

ジョッキもCCD（高速移動時の衝突抜け防止）付きの剛体です。衝撃は周囲の部材へ
力積として伝播し、耐久を失った部材は複数の物理破片へ分裂します。

## 4ステージ

1. 会議室モックアップ
2. アーロンチュア棟
3. 窓際フォート
4. レギュレーション本部

クリアすると次のステージが解放され、ステージ別ベストスコアを端末内へ保存します。
石膏ボード、ガラス、木材、コンクリート、鉄骨はそれぞれ密度、摩擦、反発、
耐久、破壊音・エフェクトが異なります。

## キャラクターデザイン

そば屋は白い仮面（黒い丸目＋赤い縦模様）、半袖Tシャツ、大型ビールジョッキを
常に維持します。描画コードにもNG変更要素をコメントで明記しています。

## カットシーン

タイトルの開始操作後に`videos/opening.mp4`、最終ステージ開始時に
`videos/event_regulation.mp4`を再生できる構成です。動画が未配置なら自動スキップします。

完成動画を追加する場合は、正典置き場
`04_GAME_ASSETS/videos/sobaya-company-breaker/`から`public/videos/`へ相対symlinkを張ります。

## 開発

```bash
npm ci
npm run dev
npm test
npm run build
```

Vite + TypeScript + Three.js + Rapier 3D。PBRマテリアル、シャドウ、霧、
昼夜グラデーション、東京の街並み、剛体衝突、支持崩壊、物理破片、
スローモーション、画面振動を実装しています。

そば屋の3Dモデルはコピーせず、`public/models/sobaya.glb`から
`04_GAME_ASSETS/voxel/models/sobaya.glb`の正典へ相対symlinkで参照します。
