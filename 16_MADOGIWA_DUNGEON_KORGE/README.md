# 窓際ダンジョン 〜地下5階の伝説のビールサーバ〜（KorGE 試作版）

アクシデンチュア本社の地下には、段ボールで増築されすぎた「窓際倉庫」が広がっている。最深部に眠る伝説のビールサーバを求めて、そば屋が潜っていくローグライクです。マップはランダムに生成し、ターン制で進みます。

[KorGE](https://korge.org/)（Kotlin製のマルチプラットフォーム2Dゲームエンジン）の試作です。今はPC（JVM）向けだけをビルドしています。

## 遊び方

- 移動: 矢印キー / WASD（1マス動くと1ターン）
- 敵に体当たりすると「片付ける」（攻撃）
- 仲間に体当たりすると話せる
- 一休み: X または .（1ターン待つ。少し回復）
- 会話を進める: Enter / Space / Z
- 段ボールの階段（↓）で下の階へ降りる。地下5階の巨大アーロンチュアを片付けると、伝説のビールサーバが出てきます

| 階 | 仲間 | もらえるもの |
|---|---|---|
| 地下1階 | とーくん | ウクレレ演奏で元気が全回復 |
| 地下2階 | よーたん | フロアの図面（地図が全部見える）と焼き鳥の差し入れ |
| 地下3階 | 福ギュン | ギュンギュンパワーで攻撃力+2 |
| 地下4階 | やめたろう | 段ボールの盾で防御力+2 |
| 地下5階 | おかやまん（画面越し） | ボス戦の前の応援 |

- 敵はすべてオフィスの物や現象です（書類の山・暴走ルンバ・からまるLANケーブル・鳴りやまない内線電話・自走シュレッダー）。ボスは段ボール製の巨大アーロンチュアです。
- 拾うアイテム: 枝豆（回復）、焼き鳥（大きく回復）、ビールジョッキ（攻撃力+1）
- 元気が尽きても、仲間に担がれて地上の屋台でビールを一杯飲み、地下1階から再挑戦します。

## 起動

Gradle 8.8 は JDK 17〜22 で動きます（JDK 25 では動きません）。JDK 21 を `JAVA_HOME` に指定して起動してください。

```bash
cd 16_MADOGIWA_DUNGEON_KORGE
JAVA_HOME=/path/to/jdk-21 ./gradlew runJvm
```

コードを保存するたびに再読み込みして開発するときは `./gradlew runJvmAutoreload` を使います。

## 動作確認（自動プレイ）

ボットがタイトルからエンディングまで遊び、要所のスクリーンショットを書き出して終了します。`KORGE_HEADLESS=true` を付けるとウィンドウを開かずにオフスクリーンで描画します。

```bash
KORGE_HEADLESS=true MADOGIWA_AUTO=1 MADOGIWA_SHOTS=/tmp/madogiwa-shots ./gradlew runJvm
```

最後に `AUTO: screen=ENDING ...` と出力されれば、全5階を通してクリアできています。

## 素材

- キャラクターの立ち絵は、採用3Dモデルのレンダー `04_GAME_ASSETS/models3d/sprites/<キャラ>/` を `resources/chars/<キャラ>` から相対symlinkで参照しています（コピーしません）。そば屋・福ギュン・やめたろう・おかやまん・ゆめみんがこれです。そば屋のジョッキ、おかやまんの画面越しの出演など、NG変更の要素はモデルのとおりに描かれています。
- とーくん・よーたんは採用3Dモデルがまだ無いので、ボクセルの4方向レンダー `04_GAME_ASSETS/voxel/model_source/previews/` を使っています。背景が単色グレーなので、起動時に透過して切り抜きます（`src/Assets.kt`）。採用モデルができたら symlink の向き先を `models3d/sprites/` に替えるだけで差し替わります。
- フォントは `04_GAME_ASSETS/fonts/MPLUSRounded1c-ExtraBold.ttf`（OFL）を `resources/fonts/` から symlink で参照しています。
- 床・段ボールの壁・敵・アイテムは、矩形と円を組み合わせてコードで描いています（画像なし）。

## 構成

- `src/main.kt`: ウィンドウ、描画、入力、自動プレイ（タイトル → ダンジョン → エンディングを1つのシーン内で切り替える）
- `src/Game.kt`: ゲームのルールと状態（ターン、戦闘、会話、敵の動き、フロア遷移）
- `src/Dungeon.kt`: フロアの生成（部屋を置いてL字の通路でつなぐ）と経路探索
- `src/Assets.kt`: フォントと立ち絵の読み込み・切り抜き

## 技術メモ

- KorGE 6.0.0（`gradle/libs.versions.toml`）と Gradle 8.8 を使います。Gradle Wrapper の配布物は `distributionSha256Sum` で照合します。
- Web版にするときは `build.gradle.kts` に `targetJs()` / `targetWasm()` を追加します。ただし今の自動プレイは環境変数を読むので、Web向けには別の切り替え方が必要です。
