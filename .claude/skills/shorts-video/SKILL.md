# Shorts編集・投稿待ち管理

ユーザーが指定した採用済み動画を編集する。制作者による除外はしない。元動画の声・内容を保ち、声の差し替えは明示された場合だけ行う。このスキルは他の編集スキルや個人の投稿待ち台帳を必要としない。

## 対象と入力

- 標準は実測60秒未満。60秒以上は勝手に切らず、抜粋範囲などユーザー指定に従う。これは制作テンプレの対象であり、YouTube全体の尺制限ではない。
- 台本・制作記録・採用ファイルを照合し、1エピソードにつき採用済み完成版1本を選ぶ。Studio登録者だけで作者を推定しない。
- 完成版、字幕なし映像（ある場合）、採用音声、既存字幕、横版URL、使用素材のクレジットを特定する。ffprobeで解像度・fps・フレーム数・音声を確認する。
- 既存Shortsと投稿記録を照合して重複を避ける。元完成版・既存投稿は上書きしない。

## 採用レイアウト

[編集テンプレートと実行手順](references/editing.md)に従う。同梱Remotionテンプレートを新しい作業ディレクトリへ初期化できる。

- 720×1280、入力fpsを維持。同じ映像を背景へ拡大し、blur・減光。中央は横動画をcontainで収め、人物とオチを切らない。
- 上に小見出し＋タイトル。白〜淡いクリーム色。下線・枠・シリーズ名等の装飾は足さない。
- 下余白の話者名28px・白、セリフ38px・白＋メンバー色の縁取り。通常1〜2行、最大3行。語尾だけを次の行やカードへ残さない。
- 色は `03_SCRIPTS/00_TEMPLATES/subtitles/member-colors.ts` を正本とする。心の声・無線も本人と同色。新規表示名は福ギュン、内部IDはfukuchan。

## 字幕・音声・クレジット

1. 既存字幕の話者・タイミングを出発点に、実発話と照合する。ASRは補助。画面に映る人物だけで話者を決めない。無言の回へ架空のセリフを追加しない。
2. 下へ移す会話字幕は元画面から除く。編集元の字幕レイヤーを外すか、字幕前映像を使う。焼き込み字幕しかなければ、その制約を明記し、人物まで切る・黒帯で雑に隠す・二重表示する方法で済ませない。
3. ニュース帯・価格・漫画の縦書き等、演出に必要な文字は維持する。
4. 映像に字幕なしrawを使っても、**音声は採用済み完成版**から戻す。元音声保持時はAACのstream copyを優先し、尺を削った場合だけ同じ終端へ切る。
5. ゆめみん等の声変更を指定された場合は、[音声設定](references/voices.md)と `02_CHARACTERS/VOICE_CAST.md` を読む。ショート化だけを理由にTTS再生成・声変更をしない。
6. 使用した声・音楽・素材のクレジットを投稿文へ残す。共有元MMUは概要欄集約だが、**このリポジトリのVOICEVOXは動画内表記が必須**。末尾カードを削る場合、必要なクレジットを`creditText`等で画面内に残す。音楽等の個別条件も確認する。

## 検証・納品

- 全編デコード、720×1280、fps・フレーム数・尺・採用音声との一致を確認。テンプレートは機械検証の結果を出すが、視聴合格とは扱わない。
- 先頭・末尾・代表カット・最長字幕・全字幕カード中間点を実フレームで見て、文字切れ・二重字幕・話者名・色・オチ・クレジットを確認。通し試聴で二重音声・欠落・クリック・同期ずれを確認し、未試聴なら明記する。
- 完成品はエピソード直下の `final_remotion_shorts_9x16.mp4` 等。再編集は別名で保存し、採用ファイルを台帳へ記録する。
- Gitにはコード・lockfile・字幕/編集JSON・監査結果・投稿文を残す。動画・node_modules・中間音声・監査画像・ASRキャッシュはローカル保持。採用した再生成用音声は制作側の管理方針に従う。
- 複数本は `order / title / source / output / manifest / metadata / status / youtubeId` を持つ投稿待ち一覧にする。週5本等の並べ方はユーザー指定に合わせ、個人の既存キューへ自動追加しない。

## 公開

「ショートに編集」「投稿準備」は書き出しと確認まで。明示的なYouTube公開依頼がある場合だけ、利用者本人の既存認可で公開し、動画IDと公開・処理完了を確認する。別人のOAuthや再開セッションをコピーしない。

通常は横版とは別のYouTube動画として扱い、元の横版IDを置換しない。Studioへの別エピソード登録や定期公開は別の明示依頼がある場合のみ。投稿済み・転送中の記録がある場合は同じID/再開処理を確認し、失敗したからと別IDで投稿し直さない。
