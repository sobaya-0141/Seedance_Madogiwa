# そば屋無双2D 敵のデザイン画（正典）

敵の絵（アニメのコマ）はすべて、ここのシートを参照画像として作り、下のチェックリストで1項目ずつ照合する。1項目でもズレていたら作り直す。プロンプトは `17_SOBAYA_MUSOU_2D_KORGE/art_prompts/enemy_design_prompts.md`（シート）と `enemy_anim_prompts.md`（アニメ）。

ボタンの数などは、プロンプトの指定ではなく**承認したシートに描かれている数が正**（2026-11-11 承認）。

## 警備員（guard_sheet.png）

身長はそば屋の約0.95倍。中肉で、そば屋より明らかに細く小さい。

1. 灰青色の制帽（黒いつば）。正面に**銀色の丸い帽章1つ**（円の中に5つ星）
2. 水色の**半袖**シャツ（襟付き）。前のボタンは**白4つ**。胸ポケット**2つ**（フラップ付き・ボタン1つずつ）。両肩に肩章
3. 黒いベルトに**銀色の四角いバックル**
4. 濃いグレーのズボン、黒い編み上げ靴
5. **素手**（手袋なし）。警棒・無線・武器は持たない
6. 短い黒髪、まじめで少し気弱な顔（汗のしずく程度の表現は可）。肌は自然な肌色

## 警備隊長（captain_sheet.png）

身長はそば屋とほぼ同じで、警備員より太い（お腹の出た巨漢）。ミニボス。

1. 紺の制帽（黒いつば）。正面に**金色の帽章1つ**（円の中に5つ星）と、つばの上に**金の飾り紐**
2. 濃い青の**長袖**シャツ（襟付き）。前のボタンは**白6つ**。胸ポケット**2つ**（フラップ付き）。両肩に**金の線2本ずつ**の肩章
3. 紺のベスト（肩ベルト付き）。前に**ポーチ2つ**（ボタン1つずつ）
4. **白い手袋**（両手）
5. 黒いベルトに**金色の四角いバックル**
6. 紺のズボン、黒いブーツ
7. **太い黒の口ひげ**、太い眉の、厳しいけれどコミカルな顔。短い黒髪
8. 武器・警棒は持たない

## 警察官（police_sheet.png）

身長は警備員と同じくらい（そば屋の約0.97倍）。中肉。ステージ1エリア2から出てくる雑魚。

1. 紺の制帽（黒いつば）。正面に**金色の6つ星**（円なし）の帽章1つ
2. 紺の**長袖**シャツ（襟付き）。胸ポケット**2つ**（フラップ付き）
3. **黒に近い紺のネクタイ**
4. 黒いベルトに**銀色の四角いバックル**、**黒いポーチ2つ**
5. **白い手袋**（両手）
6. 紺のズボン、黒い靴
7. **黒い警棒を右手**に持つ（正面図では画面の左側、横向きでは手前、後ろ姿では画面の右側）
8. 短い黒髪、まじめで人の良さそうな笑顔。肌は自然な肌色

## 巡査部長（sergeant_sheet.png）

身長は警備隊長と同じくらい（そば屋の約1.0倍）で、警察官より一回り太い。警察官と同じ警察の制服で、ミニボス。

1. 紺の制帽（黒いつば）。正面に**金色の6つ星を円で囲んだ帽章**1つと、つばの上に**金の飾り紐**

3. **黒に近い紺のネクタイ**（金のネクタイピン）
4. 黒いベルトに**金色の四角いバックル**、**黒いポーチ2つ**

## 警部（boss_sheet.png）

身長はそば屋の約1.03倍で、一番大きい。がっしりした巨漢。全ステージのボス。

1. 黒い制帽（黒いつば）。正面に**金色の8つ星を円で囲んだ帽章**1つと、**金の飾り紐**
2. 黒に近い**スリーピース**（上着・ベスト・ズボン）。上着の前ボタン**2つ**
3. **白いシャツ**と**紺のネクタイ**
4. **白い手袋**（両手）
5. 黒い革靴
6. 武器・警棒は持たない
7. 角ばったあご、太い眉、黒髪。自信満々のにやけ顔
8. 怒りの段階: **顔が真っ赤**、眉がつり上がり、歯を食いしばり、**両耳から白い湯気**（コミカル）
