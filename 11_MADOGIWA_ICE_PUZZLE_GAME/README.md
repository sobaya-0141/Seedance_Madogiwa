# 窓際族０

やめたろうの冷却最適化プログラムがバグを起こし、オフィスが全面凍結。
氷上を一直線に滑り、重要資料とビールを全部回収して赤提灯の出口から脱出する、
固定4方向の2.5Dパズルゲームです。

## 遊び方

- 一度方向を入力すると、壁・仲間・出口へ到達するまで止まれません
- 重要資料とビールは滑走中に通過回収し、そのまま滑り続けます
- 壁と仲間をストッパーに使い、回収物を通るラインを組み立てるのが攻略の鍵です
- 全回収すると赤提灯の出口が緑色に変わり、脱出可能になります
- カメラにはプレイヤー周辺の約10マスが映り、白枠付きフロアマップで全体を確認できます
- 「1手戻す」と「やり直す」はいつでも使用できます

### PC

- 移動: 矢印キー / WASD
- 1手戻す: `Z` / Backspace
- やり直す: `R`

### スマートフォン

- 画面の十字ボタン
- 盤面を上下左右へスワイプ

斜め移動と滑走中の方向転換は存在しません。

## ステージとエンディング

- 全5ステージ
- 盤面は12×12から20×17まで段階的に拡大
- 各ステージに最短解と同じPAR手数（7・10・15・18・24手）と自己ベストを設定
- 最終ステージをクリアすると、やめたろうがバグを修正
- 重要資料は無事、ビールはちょうど飲み頃となり、全員笑顔で乾杯します

## 技術メモ

- Vite + TypeScript + Three.js
- ゲーム判定は整数座標の2Dグリッドのみで処理
- Three.jsはグリッド状態を表示する描画層で、移動可否や衝突判定には使用しません
- 外周壁、机、植木鉢、書庫、サーバーラック、パーティション、複合機を手続き型3Dアセットとして描画
- 凍結床は霜・氷の濃淡・ひび割れを合成したCanvasTextureと透明な氷膜の二層構造
- プレイヤーは正典の`yametaro.glb`
- ステージごとにそば屋・福ちゃん・たこさん・ゆめみん・おかやまんがストッパー／案内役として登場
- `public/models/*.glb`は`04_GAME_ASSETS/voxel/models/*.glb`への相対symlinkです
- オープニングは`videos/opening.mp4`、エンディングは`videos/ending.mp4`を参照します。動画未配置時は自動スキップされ、ゲーム本体だけで最後まで遊べます

## 開発

```bash
npm install
npm run dev
npm test
npm run build
npm run build:sites
```

`npm test`では、4方向以外の移動が存在しないこと、回収物を通過回収すること、
出口の解放条件、全5ステージの最短解がPARと一致することを確認してから本番ビルドを行います。
