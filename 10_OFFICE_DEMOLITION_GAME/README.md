# そば屋のオフィス更地クラッシュ ～全部壊して快適です！～

既存作「そば屋のオフィスクラッシュ ～無限フロア大整理～」を残したまま制作した、
独立した全破壊3Dアクションゲームです。

会社公認のリノベーション業務として、広大なオフィスの机、椅子、設備、壁、天井、
床スラブ、コンクリート柱、鉄骨まで段階的に解体します。外壁を破ると麻布十番の街へ進出。
街を壊すほど巨大化したそば屋が、最後は周辺一帯を本当に何もない更地へ戻します。
一般社員は安全な隣棟から応援しており、誰も負傷しないカートゥーン物理で描いています。

## ゲーム内容

- 合計491件（オフィス304件＋街187件）の個別破壊対象
- 中央執務、会議室、書庫、サーバー設備、窓際ラウンジ、建物コアの6区画
- 外壁破壊後に開く麻布十番エリア（26棟のビル＋32件の街路設備）
- 破壊経験値による5段階の解体許可
  1. 机、椅子、PC、観葉植物
  2. ロッカー、複合機、ガラス、パーティション
  3. ドア、石膏壁、窓、天井
  4. 床スラブ、コンクリート柱
  5. 鉄骨、建物コア、基礎
- スマッシュ、つかむ／投げる、ショルダーダッシュ、快適ストンプ、超乾杯奥義
- 街を壊すほど最大5.2倍まで巨大化し、攻撃範囲・移動速度・カメラが段階的にスケール
- レベル5の超乾杯奥義で、前方を薙ぐビールビームと追尾ジョッキメテオを同時発射
- 残り28件以下、または10秒間破壊がないと起動する残存アセットレーダー
- 各レベル固有の5つの作業指示（コンボ、投擲、壁抜き、連鎖崩壊、鉄骨乾杯）
- 投げた家具による巻き込みと、支持柱を抜いたときの壁・天井・梁の連鎖崩壊
- 紙、木、布、ガラス、金属、石膏、コンクリート、鉄骨ごとの破片・音・手応え
- 230個の再利用デブリプールと、街破壊にも耐える材質別InstancedMesh瓦礫
- キーボード、ゲームパッド、タッチ操作
- 画面揺れの無効化、効果音切り替え、OSの視覚効果軽減設定
- D1への進行・作業指示の達成状況保存と、端末キャッシュによる一時的なオフライン継続
- 完全更地時の自己ベスト、クリア回数、総解体数保存
- 旧バージョンのセーブを維持したまま、街の解禁・巨大化進行を破壊済みIDから復元

## 操作

### PC

- 移動: `WASD` / 矢印キー
- スマッシュ: `Space`
- つかむ／投げる: `E`
- ショルダーダッシュ: `Shift`
- 快適ストンプ: `Q`
- 超乾杯奥義（ビールビーム＋ジョッキメテオ）: `R`
- 一時停止: `P` / `Esc`

### ゲームパッド

- 移動: 左スティック
- スマッシュ: A
- つかむ／投げる: X
- ダッシュ: B
- ストンプ: Y
- 超乾杯奥義: RB

### スマートフォン

左下の仮想スティックと、右下の5つのアクションボタンを使用します。
未解禁の操作は解体レベルとともに順番に有効になります。

## 正典モデルとデザイン

- `public/models/sobaya.glb` は
  `../04_GAME_ASSETS/voxel/models/sobaya.glb` への相対symlink
- 白い仮面と大型ビールジョッキを維持
- 3Dモデルをゲーム側へコピーせず、正典生成物を参照
- ビジュアル基準:
  `docs/concepts/total-destruction-art-direction-v1.png`

## 主な構成

- `app/OfficeDemolition.tsx`: HUD、開始／休憩／クリア画面、タッチ操作、保存同期
- `app/demolition/world.ts`: Three.js世界、入力、破壊、連鎖、カメラ、保存スナップショット
- `app/demolition/assets.ts`: 破壊可能なボクセル家具・建築モジュール
- `app/demolition/city.ts`: 麻布十番の配置、街破壊対象数、巨大化カーブ
- `app/demolition/rules.ts`: 解体レベル、作業指示、素材許可、スコア、セーブ検証
- `app/demolition/audio.ts`: 材質別のプロシージャル効果音
- `worker/index.ts`: D1保存API
- `db/schema.ts`: プレイヤー、進行状況、クリア履歴

## 開発

```bash
npm install
npm run dev
npm test
```

`npm test`は本番ビルド後、解体レベル、素材制限、街区配置、巨大化、残存レーダー、
セーブ正規化、正典モデル参照、旧作の保持、レスポンシブ操作、D1永続化を検証します。
