# そば屋の定時ダッシュ 〜バレずに脱出！DX〜

窓際族のそば屋を操作し、仲間の視界と物音を読みながら、
定時のオフィスから気持ちよく脱出する短時間ステルス・ローグライトです。

## ゲーム内容

- 一般オフィスから窓際リモート会議室まで、順番に解放される全5フロア
- 巡回、物音調査、周辺捜索、巡回復帰を行う状態遷移型AI
- レーダーと3Dフロアの両方に表示される視界コーン、物音、目的物、出口
- 「残業」「定時退社」「フライング退社」の3難易度。回収条件とスコア倍率が変化
- 残業はアイテム回収任意、定時退社とフライング退社は全アイテム回収必須
- 全アイテム回収で開く秘密の「人型の壁穴」
- 道具は段ボール「アーロンチュア」に限定。再入力するまで隠れ、任意に解除可能
- 残業と定時退社では段ボール無制限、フライング退社では3回まで
- 定時退社をデフォルト難易度に設定
- 警戒中の敵は頭上ゲージとキャラクター別セリフを維持。全ゲージ消灯が解除チャンス
- 回収アイテムは読みやすい正面向きカード表示（回転せず、上下にだけ浮遊）
- タイム、発見回数、最大発見ゲージ、回収率、秘密出口から算出するS〜Cランク
- フロア解放、難易度×ステージ別自己ベスト、PERFECT達成、退社スタンプの端末内保存
- 全回収・完全未発見・規定時間内・秘密出口で各フロアのPERFECTを達成
- 日替わりで視界、足音、巡回速度などが変化する「本日のレギュレーション」
- PCのキーボード操作とスマートフォンの仮想スティック／タッチ操作
- Web Audioによる足音、発見、回収、ガジェット、リザルトの効果音

一般社員と窓際族の関係は良好です。捕まる表現は処罰ではなく、
仲間との立ち話が始まって最速退社に失敗するコミカルな演出です。

## 操作

### PC

- 移動: `WASD` / 矢印キー
- しのび足: `Shift`
- 段ボールを隠す／解除: `E`
- 一時停止: `P` / `Esc`

### スマートフォン

- 左下: 仮想スティック
- 右下: 段ボールを隠す／解除
- 右下上部: しのび足

## 開発

```bash
npm ci
npm run dev
npm test
```

`npm test`はステージデータ、スポーン位置、巡回経路、スコア規則を検証した後、
TypeScriptの型チェックとViteの本番ビルドを実行します。

## 主な構成

- `src/main.ts`: ロビー、HUD、入力、進行保存
- `src/game.ts`: Three.jsシーン、ステルスAI、物音、回収、ガジェット、リザルト
- `src/level.ts`: 全5フロアのデータ定義
- `src/rules.ts`: 難易度、日替わり条件、段ボール、スコア評価
- `src/radar.ts`: 監視レーダー
- `src/profile.ts`: 端末内プロフィール
- `src/audio.ts`: Web Audio効果音
- `src/geom.ts`: 衝突と視線判定
- `src/voxel-character-kit.ts`: 共通ボクセルリグとモーション

## 正典3Dモデル

`public/models/*.glb`は
`../04_GAME_ASSETS/voxel/models/*.glb`への相対symlinkです。
GLBをゲーム内へコピーしたり直接編集したりせず、正典モデルを参照します。
