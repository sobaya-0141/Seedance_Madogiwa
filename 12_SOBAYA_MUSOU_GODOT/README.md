# そば屋無双 〜ビール工場強奪作戦〜（Godot 4・体験版）

**体験版**としてゲームサイトで公開中（効果音・BGMなし、難易度は未調整、タッチ操作は未対応）。

ビールが足りないそば屋が、押し寄せる警備員や警察官をビールジョッキでなぎ倒しながら進む3Dアクション。ステージは3つで、それぞれ3つのエリアを突破する。

| ステージ | 舞台 | 目的 |
|---|---|---|
| 1 | 架空の「ゴールデン麦酒 第一工場」 | 製造ラインのできたてビールを奪う |
| 2 | 麻布十番駅 → あくしでんちゅあ本社ビル | 確保したビールを持って、追ってくる警察官を蹴散らしながら本社ビルへ |
| 3 | あくしでんちゅあ本社ビル | 「業務中の酒は禁止！」と止めに来る本社警備隊を突破し、窓際の立ち飲み処にビールを届けて開店する |

タイトル画面で ← → を押すとステージを選べる。ステージをクリアすると Enter で次のステージへ進む。

攻撃はドタバタ表現にしている。殴られた敵は吹っ飛んで頭の上に★を回し、床に沈んで退場する（流血・死亡表現はしない）。

## 遊び方

```bash
godot --path 12_SOBAYA_MUSOU_GODOT
```

### 流れ

どのステージも、雑魚は隊長を倒すまで出続ける（同時に最大32人）。ある程度倒すと隊長が出てきて、隊長を倒すと残りの雑魚はまとめて吹っ飛んで退場し、ゲートが開いて次のエリアへ進める。画面上部には残り人数ではなく「敵を蹴散らせ」「◯◯を倒せ！」と目的だけを出す。最後のエリアのボス（地響きの衝撃波を使う。体力が半分を切ると怒って速くなり、地響きを2連発する）を倒すとゴールが光り、F 長押しでクリア。

**ステージ1 ゴールデン麦酒 第一工場**

1. **正門ヤード**: 警備員。14人倒すと「警備隊長」が出る。隊長を倒すとシャッターが開く
2. **倉庫**: 警備員と警察官。22人倒すと「巡査部長」が出る
3. **製造ライン**: 警察官中心の雑魚と、出荷口を守る「警部」。出荷口で F 長押しでビールを確保

**ステージ2 麻布十番 〜本社への道〜**

1. **麻布十番駅前**: 地下鉄の出入口から出たところ。工場から追ってきた警備員と警察官。15人倒すと「交番所長」が出る。所長を倒すと規制線（バリケード）が左右に開く
2. **麻布十番商店街**: アーチ看板・提灯・たい焼きの屋台。警察官と白バイ隊員。22人倒すと「白バイ隊長」が出る
3. **本社前広場**: 正面にあくしでんちゅあ本社ビル、遠くに東京タワー。雑魚と「機動隊長」。エントランスで F 長押しで入館

**ステージ3 あくしでんちゅあ本社ビル**

1. **1F エントランスロビー**: 受付・来客用ソファ・エレベーター。本社警備隊と「警備主任」（15人倒すと出る）。主任を倒すとセキュリティゲートが開く
2. **12F 一般オフィス**: 島型デスクと会議室。警備員と「警備課長」（22人倒すと出る）
3. **窓際族エリア**: 木の床・アーロンチュア・テント・BBQ・やめ太郎の手配書、奥の窓に東京タワー。雑魚と「警備本部長」。立ち飲み処のカウンターで F 長押しでビールを納品して開店

**隠しステージ 本社屋上ヘリポート（隠しボス・土下座王 いーさん）**

ステージ3で立ち飲み処を開店すると、画面が赤く明滅して「WARNING」と警告音が出て、夜の本社屋上ヘリポートで隠しボスのいーさんと1対1で戦う（雑魚は出ない。タイトル画面からは選べない）。いーさんは競謝（土下座の速さを競う競技）の不動の王者で、とてつもない土下座で攻撃してくる。どの技も地面に赤い予告が出るので、回避（前転の無敵）か距離で避ける。倒すと完全制覇。

- **土下座ダイブ**: 高く跳んで宙返りし、狙った場所へ土下座で着地する。赤い円の中は地響きで大ダメージ
- **土下座スライド**: その場で土下座し、そのまま床を滑って一直線に突っ込む（赤い長方形が通り道）
- **連続土下座**: その場で素早く何度も土下座し、外へ広がる輪の衝撃波を出す（輪の線に触れると当たる。回を重ねるほど輪が大きい）
- 土下座のあとは少しのあいだ頭を上げられず、受けるダメージが1.6倍になる（反撃のチャンス）
- 体力が半分を切ると「本気の土下座」: 赤く光り、技の間隔が短く、ダイブは2連続・連続土下座は5連・スライドは途中で1回向きを変える
- 技の強さ・速さは `iisan_boss.gd` の冒頭（`DIVE_DMG` など）と各技の関数、体力は `main.gd` の `ENEMY_TYPES` の `"iisan"`

ステージ2・3には、戦いに加わらない通行人や一般社員がいる（騒ぎに動じず電話・立ち話・デスクワークを続ける。攻撃は当たらない）。店名などは一般名詞だけにしてあり、実在の店・ブランドは出さない。

### システム

- **コンボ**: パンチ → フック → パンチ → 叩きつけ（衝撃波で打ち上げ）。攻撃中に次の入力を受け付ける。攻撃中はひるまない
- **チャージ攻撃**: 通常攻撃の途中からでも出せる。広い範囲を大きく吹っ飛ばす
- **必殺ゲージ＝ジョッキのビールの量**: 攻撃を当てる・攻撃を受けるとたまる（たまり方は `player.gd` の `MUSOU_PER_HIT` / `MUSOU_PER_DAMAGE`。1ステージで1〜2回使える程度）。満タンで必殺技（約3秒、ビールの渦をまとって周囲をなぎ倒し、最後に泡がはじける。無敵）。画面にゲージの説明文は出さない
- **回避**: 前転。転がり始めは無敵
- **回復**: 倒した敵がときどき落とす瓶ビール（体力と必殺ゲージが少し回復）。隊長・巡査部長・警部は大ジョッキを落とす（体力50%＋必殺ゲージ半分）
- 敵は同時に3人までしか殴りかかってこない（残りは周りを囲んで順番を待つ）。隊長・巡査部長・警部は大技でしかひるまない

## 構成

- `main.gd`: ゲーム進行（エリア・敵の出現・制圧判定・ゴール）、戦闘の当たり判定、ナビメッシュ、カメラ、UI、演出
- `player.gd`: そば屋。モーションは共用モデルに入っているもの（`Hybrid_MugPunch` / `Hybrid_MugHook` / `Hybrid_MugSmash` / `MugAttack` / `Hybrid_MugRun` / `Procedural_RollForward` / `DanceVictory` など）。ジョッキは右手の `PropSocket.R` に外付けし、液量（`Fill` モーフ）で必殺ゲージを表す
- `enemy.gd`: 敵。見た目は Tripo で作った7体（`models/tripo/` → `04_GAME_ASSETS/models3d/tripo/`、`main.gd` の `ENEMY_TYPES` の `"model"`）。動きは今までどおり CC0 のマネキン素体（非表示）で再生し、`retarget.gd` が毎フレーム Tripo のモデル（Mixamo 形式の骨）へ写す。隊長クラスは同じ見た目を大きくしたもの。`"model"` を外すと、従来の色塗りマネキンに戻る
- `retarget.gd`: マネキン（T ポーズ）の骨の回転を、腕を下ろした姿勢の Mixamo 骨へ写す。起動時に骨の向きをそろえる回転を求め、毎フレーム「休止姿勢からの回転差」を親から順に入れる。腰は位置も写す。指は写さない
- `stage_base.gd`: ステージの共通部分（寸法・エリア・文言の置き場、障害物、ゲートの開閉、敵の出現位置、通行人の置き場、東京タワーなどの組み立て道具）
- `stage_factory.gd`: ステージ1。工場の建物・障害物・シャッター・コンベア
- `stage_street.gd`: ステージ2。駅前・商店街・本社前広場の街並み、規制線、本社ビルの外観
- `stage_office.gd`: ステージ3。ロビー・オフィス・窓際族エリア、ガラスの仕切り、窓の外の眺め
- `stage_secret.gd`: 隠しステージ。夜の本社屋上ヘリポート（ヘリポートの円とH・航空障害灯・投光器・眼下の夜景と東京タワー）。`win_on_boss` でボスを倒したらそのままクリア
- `iisan_boss.gd`: 隠しボスのいーさん（`enemy.gd` を継承）。歩き・パンチは他の敵と同じリターゲット、土下座は `models/tripo/iisan_dogeza.glb` に入れたアニメーション `Dogeza`（立つ→正座→土下座）の進み具合を直接指定して見せる。予告の赤い円・長方形もここで出す
- `sounds/`: 警告音 `warning.wav` と地響き `boom.wav`（`make_sounds.py` で波形から作った自作の音。外部素材なし）
- `models/`: 共用モデルへの相対symlink（コピーしないこと）
  - `sobaya_hq.glb` → `04_GAME_ASSETS/models3d/sobaya.glb`
  - `beer_mug.glb` → `04_GAME_ASSETS/models3d/props/beer_mug.glb`
  - `mannequin_base.glb` / `mannequin_addon.glb` → `04_GAME_ASSETS/models3d/mobs/`（CC0）
  - `kenney/<パック>/<名前>.glb` → `04_GAME_ASSETS/models3d/kenney/`（CC0。使うモデルだけリンクする。`Textures/colormap.png` も同様）
  - `tripo/iisan_dogeza.glb` → `04_GAME_ASSETS/models3d/tripo/iisan_dogeza.glb`（いーさんの Tripo モデルに土下座のアニメーションを付けたもの。`04_GAME_ASSETS/props_blender/pose_iisan_dogeza.py -- --export-anim` で作る）
  - `*.glb.import` は `gltf/embedded_image_handling=3`（テクスチャをこのフォルダへ書き出さない）
- `textures/<名前>/*.jpg`: 床・壁の PBR テクスチャ（CC0）。`04_GAME_ASSETS/textures/` への相対symlink。`.import` は VRAM 圧縮・ミップマップあり、`*_nor_gl_*` は法線マップとして取り込む

敵の強さは `main.gd` 冒頭の `ENEMY_TYPES`、エリアごとの敵の割合・隊長と隊長が出るまでの撃破数（`captain_at`）は各ステージの `_init()` の `zones`、そば屋の技の威力・範囲・速さは `player.gd` 冒頭の `COMBO` / `CHARGE` にまとめてある。通行人・一般社員の服の色は `main.gd` の `BYSTANDER_TYPES`。

障害物は各ステージの `obstacles`（矩形、`_obstacle()` で足す）が当たり判定の正本で、敵の経路探索用のナビメッシュも同じ矩形からステージを読み込むたびに作っている。障害物を足すときは見た目と一緒に `_obstacle()` も呼ぶ。

ステージを増やすときは `stage_base.gd` を継承したファイルを作り、`main.gd` の `STAGES` に足す。

### 見た目（PC版向け）

- 時間帯はステージごとに `_build_environment()` で決める（工場＝昼、麻布十番＝夕方、本社ビル＝朝）。空は自作のシェーダー（グラデーション・太陽・雲）。SSAO・SSIL・映り込み（SSR）・ボリュメトリックフォグ・柔らかい影を使う。Web版（Compatibility）ではこのうち SSAO などが効かない
- 箱・円柱は自作の `SURFACE_SHADER`（ムラ・足元の汚れ・面取りのハイライト）。`surface = "plaster"` などを入れてから `_box()` を呼ぶと、CC0 テクスチャの質感が付く（`SURFACES`）
- 床はステージごとのシェーダーで、`_build_floor()` に渡したテクスチャを貼る
- Kenney のモデルは `_prop("パック/名前", 位置, 向き, 横幅 or 高さ)` で置く。大きさを合わせて、足元の矩形を当たり判定にも足す
- 見た目の確認は定点カメラで撮る: `godot --path . -- --auto --stage=2 --view=1 --shot=/tmp/v.png --frames=200`（`--view` は各ステージの `views` の番号。UI は消える）

## Web版（ゲームサイトで公開）

`export_presets.cfg` の「Web」プリセットでブラウザ向けに書き出す。GitHub Pages はスレッド用のヘッダー（COOP/COEP）を付けられないので、スレッドなし版（`variant/thread_support=false`）にしている。ブラウザでは Compatibility（WebGL2）描画になり、SSAO などは効かない。

```bash
godot --headless --path . --export-release "Web" build/web/index.html
python3 -m http.server 5195 --directory build/web   # http://localhost:5195 で確認
```

- 書き出しには Godot 4.7.2 の Web 用テンプレートが必要（エディタの「エクスポートテンプレートの管理」、または公式リリースの `Godot_v4.7.2-stable_export_templates.tpz` から `web_nothreads_release.zip` を `~/Library/Application Support/Godot/export_templates/4.7.2.stable/` へ）
- ゲームサイトへは `GAMES_PORTAL/games.json` の `"engine": "godot"` の項目で載せている。main へ push すると、GitHub Actions が Godot とテンプレートを公式リリースから取得（SHA512-SUMS で照合・キャッシュ）して書き出す
- `web_assets/` はサイト用の追加ファイル（カード画像 `og.png`）。`.gdignore` で Godot の取り込み対象から外している
- 日本語はブラウザで端末のフォントが使えないので、同梱フォント `fonts/MPLUSRounded1c-ExtraBold.ttf`（`04_GAME_ASSETS/fonts/` への相対symlink、OFL）を使う
- タッチ操作は未対応（キーボード・ゲームパッドのみ）

## 動作確認用の自動プレイ

そば屋を自動操作して通しで遊ばせ、指定フレームで画面を保存して終了する。体力が減ると自動で回復するので、必ず最後まで進む。

```bash
godot --path . -- --auto --shot=/tmp/end.png --frames=12000                 # 通しプレイ（120フレームごとに状況をログ出力）
godot --path . -- --auto --shot=/tmp/run.png --frames=11000 --snap=900,4500   # 途中も撮る（/tmp/run_900.png ...）
godot --path . -- --auto --musou-at=700 --shot=/tmp/m.png --frames=900 --snap=760   # 必殺技を撮る
godot --path . -- --auto --stage=2 --shot=/tmp/s2.png --frames=14000             # ステージ2から始める（1〜3）
godot --path . -- --auto --stage=4 --shot=/tmp/boss.png --frames=12000           # 隠しボス戦から始める
godot --path . -- --auto --stage=3 --secret-test --shot=/tmp/w.png --frames=2400  # ステージ3をすぐクリア扱いにして、WARNING から隠しボス戦を見る
```

マネキンの読み込み時に出る `UVs are required to generate tangents.` は、UVを持たないジョッキ部品についての警告で、表示には影響しない。
