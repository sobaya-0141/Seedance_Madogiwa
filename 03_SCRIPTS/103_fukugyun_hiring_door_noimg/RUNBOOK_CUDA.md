# RUNBOOK — 103 福ギュン誕生（MiniMax H3 / 全19チャプターR2V）

画像なし制作（`/no-image-video`）のラン。**キーフレームは1枚も無い**。H3へ渡すのは
キャラクターシート・扉のセット参照・セリフwav・プロンプトだけ。

- モード: **全チャプターR2V**（I2Vは1本も無い → Colabノートブックは `h3_colab_r2v.ipynb` 1本だけ）
- 合計: 19チャプター / 2169フレーム / 24fps = 90.38秒
- 台本・入力表・プロンプトの正典: `script.md`
- 人間承認済みのチャプター計画: `chapter_plan.md`（全章 `APPROVED`）

## 所要時間の目安

`build_h3_run_package.py` の見積り（L4 + sage・直列）:

| | フレーム | 目安 |
|---|---|---|
| パイロット（ch2のみ） | 107 | 約12分 |
| 残り18チャプター | 2062 | 約3時間52分 |
| 合計 | 2169 | **約4時間4分** |

1チャプターあたりの内訳は `h3/` 生成時のログに章ごとに出る（90f=11分 / 107f=12分 / 124f=14分 / 192f=20分）。

## 手順

1. Driveの `h3_inputs/` 直下に `103_fukugyun_hiring_door_noimg_h3_bundle.zip` をファイル名そのままで置く。
2. `h3/h3_colab_r2v.ipynb` をColabで開き、L4以上（Pay As You Go / Colab Pro）で実行する。
   無料T4は配管検証用で、本番生成には足りない。
3. **ch2だけ先に生成する**（セル1の `CHAPTERS` を `[2]` にする）。`script.md` の
   「Generation & assembly protocol / Step 1」のチェックリストを全項目PASSさせる。
   特にこのランで落ちやすいのは:
   - 添付シートがそのまま1フレーム目に出る（パネル・白背景・文字）
   - やめ太郎がノッカーの顔ではなくチビ人形の全身で出てくる
   - 扉の蝶番・ハンドルの左右が入れ替わる
   - 福ちゃんの顔や体が画面に入ってくる（ch2は手と袖だけ）
4. PASSしたら `CHAPTERS` を全章に戻して一括生成する。
5. 成果物は `h3_outputs/103_fukugyun_hiring_door_noimg/` に貯まる。ローカルへ回収する。

## 回収後（ローカル）

1. `./assemble.sh <mp4のあるディレクトリ>` — フレーム数照合 → 結合 → コンタクトシート生成まで一気に行う。
   フレーム数が `script.md` の宣言と違うチャプターがあれば結合せずに止まるので、そのチャプターを再生成する。
2. `_contact_sheet.png` を**拡大して**目視する。画像なし制作の主な事故は「台本に無い物が湧く」。
   このランで特に見るもの: 章ごとの人数、ch6の扉の枚数（ちょうど5枚）、画面内の文字、
   おかやまんが室内に立っていないか、ch11でおかやまんが怒り顔になっていないか、紙が白紙のままか。
3. **Remotionで文字を合成する**（`script.md` Step 4）。ch15に「福ちゃん」、ch17に
   「福ちゃん」→「福ギュン」の変形アニメーション。**ch15/ch17の文字は改名前なので「福ちゃん」が正**。
4. 合成後に通しで再生し、全セリフがローカルのテイクの声になっているか確認する。

## 再生成するときの注意

- プロンプトは `script.md` の `- Motion prompt:` を**逐語**で使う（`extract_prompts.py` → `chN_prompt.txt`）。
  要約・短縮しない。
- ワークフローJSONを作り直したら必ず
  `python3 .claude/skills/no-image-video/check_workflows_match_script.py 03_SCRIPTS/103_fukugyun_hiring_door_noimg`
  を通す。`<Picture N>` の**順序**がプロンプト内のタグの意味を決めるため、入れ替わると全タグが別人を指す。
