# そば屋のビールダッシュ

正解レーンを見抜いて、一気に乾杯！

そば屋を左右に動かし、赤坂の3レーンへ散らばったビールを集めながら
立ち飲み処まで458mを疾走する3Dタイムアタックです。
操作を左右移動だけに絞り、ビールの予告列から正解レーンを読み、
連続取得する気持ちよさを主役にしています。難度の異なる3ステージから
選んで遊べます。

## 遊び方

- そば屋はゴールまで自動で前進する
- PC: `A` / `D` または左右矢印で移動
- スマホ: 左右ボタン、画面左右のタップ、横スワイプで移動
- STAGE 1の基本速度は42.5km/h。ビールを10杯集めるごとに8%上がり、
  40杯で最大1.28倍（54.4km/h）に到達する
- STAGE 2は基本44.0km/h、STAGE 3は基本45.4km/hから開始する
- 障害物に当たると2秒間、速度が0.72倍になる
- コース上の予告列を読み、その先の正解レーンへ移動する
- 正解すると同じレーンに約0.15〜0.2秒間隔のビール列が続く
- 分岐は約2.5〜3秒おき。高速でも判断回数を増やしすぎない設計
- 障害物すれすれを通ると「ギリギリ快適！」で短時間加速
- `P` / `Esc` または右上ボタンで一時停止

## 3ステージ

### STAGE 1 赤坂ビールロード ★☆☆

- 現在の基本ルールを学ぶステージ
- 「予告3杯 → 2レーン障害 → 同じレーンの長いビール列」
- 最高速でも主要判断は約2.52秒間隔
- ゴール前は全レーンにビールが並ぶ乾杯ラッシュ

### STAGE 2 窓際BBQスラローム ★★☆

- 予告が2杯になり、主要判断は最高速で約2.30秒間隔
- 一部の正解ルートは、直進の途中で隣レーンへカーブする
- 最初の正解だけで安心せず、ビール列の先を読んで二段階で判断する
- 乾杯ラッシュも2レーンだけになり、最後まで進路を選ぶ

### STAGE 3 WANTEDナイトラン ★★★

- 基本45.4km/h、最大58.2km/hの最高難度
- カーブするビール列と、3レーンを横断する動く樽が交互に登場
- 主要判断は最高速で約2.22秒間隔
- ゴール前は1レーンを蛇行する金ビール列を追う

後半ステージは、人気ランナーの「収集物でルートを示す」「動く障害物を読む」
「ステージ固有の仕掛けを段階的に追加する」という考え方を、
左右移動だけのルールへ落とし込んでいます。

## コースの変化

- 赤坂オフィス街 → 窓際BBQ通り → レギュレーション区 →
  WANTED BONUS ROUTE → 立ち飲み処前、と景色と看板が変化
- STAGE 1の通常分岐は「予告3杯 → 2レーン障害 → 正解レーンの8杯列」で構成
- やめたろう区間は正解レーンに金ビールを含む長いボーナス列が続く
- ゴール前50mは障害物なしの「乾杯ラッシュ」

## マドギワメンバーの支援

道沿いには全メンバーが登場し、通過時に固有の支援が発動します。

- とーくん: ウクレレの「ALOHA BOOST」で3秒加速
- よーたん: ギターの一撃で前方の障害物を1列消去
- 福ちゃん: 「ギュンギュンGUARD」で接触を1回無効化
- おかやまん: 中間地点の大型スクリーンに実写でリモート出演
- ゆめみん: 「BONK!」で減速を解除し、短時間加速
- やめたろう: WANTED金ビール区間を案内
- たこさん: 触手パワーで3レーンのビールを引き寄せる
  （高難度ステージほど効果時間が短くなる）

各ボクセルモデルはキャラクター設定のNG変更要素を維持しています。
おかやまんだけは意図的に正典写真を使い、穏やかな笑顔と
スクリーン越しの出演スタイルを守っています。

## ゴールと記録

ゴール時に `分:秒.百分の一秒` でタイムを表示します。端末内には次の3記録を
ステージごとに別々に保存します。

- 最速ゴールタイム
- 1プレイの最多提供数
- ノーヒット最速タイム

リザルトではタイム、提供数、最高速度、最大ビール連続数、
正解ルート数と最大ルート連続数、ニアミス回数、接触回数を表示。
提供数によってC・B・A・Sランクを判定し、実写のおかやまんが
大型スクリーン越しに講評します。

## キャラクターと正典アセット

`public/models/*.glb` は
`../04_GAME_ASSETS/voxel/models/*.glb` への相対symlinkです。
GLBをゲーム内へコピーしたり、手作業で編集したりしません。
おかやまんの写真も `02_CHARACTERS/Okayaman.jpg` をsymlink参照します。

## カットシーン

タイトルの開始操作後に `videos/opening.mp4` を再生できる構成です。
動画がまだ配置されていない場合は自動でスキップし、そのままゲームが始まります。
完成動画を追加する場合は、正典置き場
`04_GAME_ASSETS/videos/sobaya-beer-run/opening.mp4` から
`public/videos/opening.mp4` へ相対symlinkを張ります。

## 開発

```bash
npm ci
npm run dev
npm test
npm run build:sites
```

Vite + TypeScript + Three.jsで構成されています。ビールと障害物のコースは、
全レーンが同時に塞がらない検証済みパターンをシード付きで組み替えます。
通常の`build`はGitHub Pages向け、`build:sites`はSites公開向けです。
