# そば屋のビールダッシュ

> 正解レーンを見抜いて、一気に乾杯！

実装前の原案をプレイテストに合わせて更新したゲームデザイン。
458mタイムアタック、収集加速、接触減速、ニアミス、全メンバー支援、
複数記録に加え、高速ルート選択と同一レーンの連続取得を実装した。
旧フィーバー操作は廃止し、左右移動だけで完結させている。
プレイテスト後、基本ルールを保つSTAGE 1に加え、二段階ルートのSTAGE 2、
動く障害物を組み合わせたSTAGE 3を追加した。
現在の遊び方と開発手順は `README.md` を参照する。
添付参考画像のような「後方追従カメラ＋3レーン」を、窓際族物語の正史と
キャラクター設定に合わせて独自化する。正史年表への追加はまだ行わない。

## 1. 類似人気作の調査

調査日: 2026-07-28

| 作品 | 人気規模の目安 | 遊びの核 | この企画への学び |
|---|---:|---|---|
| Subway Surfers | パブリッシャー公称40億DL超、Google Play 10億DL超 | 3レーンを少ないスワイプ操作で走り、列車を避けながら収集。定期的な都市・イベント更新 | レーン移動だけでも、収集物の並びが「進むべき道」になれば判断が連続する |
| Temple Run / Temple Run 2 | 開発元公称で2作合計25億DL超。Temple Run 2はGoogle Play 10億DL超 | 逃走、加速、ターン、ジャンプ、スライド、環境変化 | 速度上昇と景色の切り替えが、同じ入力の繰り返しを盛り上げる |
| Minion Rush | 開発元公称12億DL超 | バナナ収集、障害回避、ガジェット、衣装、IPらしいコミカルな演出 | 汎用ランナーへキャラクターを載せるだけでなく、収集物・演出・進行をIPの言葉に統一する |
| Talking Tom Gold Run | Google Play 5億DL超 | 奪われた金を回収し、キャラクターや家の発展へ還元 | 1プレイ中の収集が、終了後の目に見える成果へつながると目的が明快になる |
| Sonic Dash | Google Play 5億DL超 | リング収集、高速走行、キャラクター解放、ボス戦、ゾーン発展 | 一定間隔のセットピースが走行の単調さを切り、IP固有の気持ちよさを作る |

### 人気作に共通する設計

1. 最初の数秒で理解できる入力
2. 収集物の列そのものがルート案内になる
3. 安全な少量ルートと、危険だが大量に取れるルートが並ぶ
4. 徐々に速度とパターンを強くする
5. 収集、コンボ、パワーアップを派手な音と画面反応で即時に返す
6. 走った成果を、解放・発展・記録など次の目的へつなぐ

### 今回そのまま採用しない要素

- 初期版ではジャンプとスライドを入れない。左右移動だけの精度を先に磨く
- 一度の接触で即ゲームオーバーにしない
- 複数通貨、広告復活、ガチャ、衣装販売は入れない
- 上司や一般社員から逃げる構図にしない。一般社員と窓際族の良好な関係を守る
- 他作品のUI、障害物の形、コースパターンを直接模倣しない

## 2. 窓際族物語への落とし込み

### 仮タイトル

**そば屋のビールダッシュ ～正解レーンを見抜いて、一気に乾杯！～**

### 物語上の位置

正史第15話より後の、地上の立ち飲み処で起きた新しい一日として仮置きする。
正史への採用が決まった段階で `01_WORLD/STORY_TIMELINE.md` に追加する。

### あらすじ

立ち飲み処の開店前、DIYの搬入台車から冷えたビールジョッキが
赤坂の3本の搬入レーンへきれいに散らばってしまう。
そば屋は「走れば準備運動にもなるのでメリットです！」と大型ジョッキを手に出発。
仲間たちの応援を受けながらビールを集め、最後は立ち飲み処で笑顔の乾杯となる。

世界観のStory Formulaにも対応する。

1. DIY搬入台車からビールが散らばる
2. そば屋と窓際族の仲間が開店準備に巻き込まれる
3. 3レーンの回収ダッシュが少し騒ぎになる
4. 全員笑顔で立ち飲み処を開店する

### 見た目

- 添付参考画像と同じ、そば屋の背後から進行方向を見る追従カメラ
- 舞台は一般的な郊外道路ではなく、赤坂の高層ビル街と地上の木造屋台周辺
- 遠景に東京タワー、ゴールに紺の暖簾と赤提灯
- 路面の3レーンは工事道路ではなく、DIYの白テープと段ボール看板で示す
- ビールの金色と泡の白を最も明るくし、背景はオフィスの青灰色で整理する
- 正典 `sobaya.glb` を使い、白い仮面と大型ビールジョッキを必ず維持する

## 3. コアゲーム

### 1プレイ（改善版）

- 立ち飲み処まで458mの短時間タイムアタック
- そば屋は自動で前進する
- プレイヤーは左・中央・右の3レーンだけを選ぶ
- 基本42.5km/h。ビール10杯ごとに8%加速し、最大54.4km/hになる
- 接触すると2秒間0.72倍へ減速する
- ゴールすると必ず立ち飲み処が開店し、回収数に応じてリザルト演出が変わる
- 一度クリア後に、長く遊べるエンドレスモードを解放する案は将来候補

短い完結型を先に作る理由は、ブラウザですぐ再挑戦でき、45秒の中で
初心者向け導入・判断・クライマックス・笑顔の結末を保証できるため。

### 操作

- スマホ: 画面の左半分／右半分をタップ、または横スワイプ
- PC: `A` / `D` または左右矢印
- 1入力で隣のレーンへ移動
- レーン移動中の次入力は1回だけ先行入力として保持する
- 初期版に前後移動、ジャンプ、スライドは入れない

### 独自ギミック「予告列とビールストリーム」

ビールの並び自体をルート案内にして、高速でも一目で正解を読めるようにする。

1. 分岐の手前に、正解レーンを示す3杯の予告列が見える
2. 予告を読んで、左右入力だけで正解レーンへ入る
3. 分岐を抜けると同一レーンに8杯以上のビール列が続く
4. 約0.15〜0.2秒間隔の連続取得を、音階と泡の演出で返す

約2.5〜3秒ごとに大きな判断を置き、その間は直進して報酬を味わえる。
速度感と判断の余白を両立し、高速で左右入力を連打させない。

### 障害物と失敗

- 段ボール箱
- 空のビールケース
- ぐらつくDIY看板
- ゆっくり横切る空樽
- 工具を載せた手押し台車

接触しても怪我や悲惨な表現はない。そば屋がコミカルによろけて少し減速し、
ビール連続数とルート連続数が戻る。ラン自体は続行する。
段ボールや空樽はカートゥーン的に崩れ、すぐ元へ戻る。

### ルート設計

- ビール3杯の予告列が、次に空いているレーンを自然に示す
- 分岐点では不正解の2レーンを障害物で塞ぎ、正解レーンだけを開ける
- 正解後は同一レーンに8杯以上を約2.25m間隔で置く
- 全レーンが同時に塞がるパターンは作らない
- 主要分岐は約38m間隔にして、最高速でも約2.5秒の判断間隔を保つ
- レーン移動を始めた直後に、移動先を塞ぐ生成はしない
- ランダム生成ではなく、検証済みの短いパターンを組み替えて必ず攻略可能にする

### 1プレイの難度曲線

| 時間 | 内容 |
|---|---|
| 0–8秒 | 1本のビール列で左右移動と予告列を教える |
| 8–20秒 | 予告、分岐、同一レーン8杯列のリズムを定着させる |
| 20–34秒 | 正解レーンを変えつつ、判断間隔は約2.5秒以上に保つ |
| 34–41秒 | 金ビールを含む長いWANTED BONUS ROUTE |
| 41–45秒 | 障害物なしの「乾杯ラッシュ」。大量回収して笑顔でゴール |

最後を失敗しやすい難所ではなく、腕前に応じて大きく稼げる祝祭区間にする。

### 3ステージの難度設計

| ステージ | 基本速度 | 主要判断の最短間隔 | 追加する難しさ |
|---|---:|---:|---|
| 1 赤坂ビールロード | 42.5km/h | 約2.52秒 | 予告3杯と直線ストリーム |
| 2 窓際BBQスラローム | 44.0km/h | 約2.30秒 | 予告2杯、途中で隣レーンへ曲がる二段階ルート |
| 3 WANTEDナイトラン | 45.4km/h | 約2.22秒 | 二段階ルート、横断する樽、蛇行する最終ラッシュ |

人気ランナーの設計から、Subway Surfersの進行方向から来る障害物、
Sonic Dashの収集列とゾーン固有ギミック、Temple Run 2の異なる地形ごとの
チャレンジを参照した。ただし操作は増やさず、左右選択の読みへ置き換える。
単純に反応時間を削るのではなく、STAGE 2で二段階判断を学び、
STAGE 3で静的パターンと動的パターンを交互に解かせる。

## 4. フィードバックと画面

### HUD

- 上中央: `本日の提供 24杯`
- 左上: 残り時間
- 右上: `正解ルート 5`
- そば屋の近く: 取得時の `+1`、正解時の `ROUTE CLEAR!`
- 画面下: 左右操作ボタンだけを表示
- ゴール前だけ赤提灯型の進行マーカーを表示

### 音と演出

- 取得: ジョッキが触れ合う短い「カチン」
- 連続取得: 1音ずつ音階が上がる
- ルート正解: そば屋の「快適です！」と金色の泡リング
- 接触: 柔らかい段ボール音。痛そうな音は使わない
- ゴール: とーくんのウクレレと全員の乾杯

### リザルト

スコアは通貨ではなく、世界観どおり **提供できたビールの杯数** で表す。

- C: ちょい飲み
- B: 常連で満席
- A: 立ち飲み処 大繁盛
- S: 大変驚いております

最高提供数、最大ビール連続数、正解ルート数、ノーヒットを記録する。
リザルトでは、おかやまんが敢えて実写で大型スクリーン越しに登場する。
Sランクでは「おかやまん。大変驚いております」と笑顔で講評する。

## 5. キャラクターの役割

初期版では主役の視認性を優先し、仲間は沿道と前後の演出へ置く。

| キャラクター | 役割 | 守る要素 |
|---|---|---|
| そば屋 | プレイヤー | 白い仮面、大型ビールジョッキ、常にポジティブ |
| とーくん | スタートのカウントとBGM | アロハ、麦わら帽子、ウクレレ |
| 福ちゃん | 道端で回収数を撮影して応援 | おしゃれ服、ギュンギュンポーズ |
| たこさん | ゴールで複数ジョッキを受け取る | 黒ローブ、白い顔、触手、人間の腕2本 |
| おかやまん | 全ランクの実写リザルト講評 | 穏やかな笑顔、大型スクリーン越し |

改善版では、よーたん・ゆめみん・やめたろうも沿道へ追加した。
各メンバーは障害物除去、減速解除、金ビール区間など固有の支援を持つ。
おかやまんは中間地点とリザルトの両方で、実写の大型スクリーン出演を維持する。

## 6. 初期版と将来案の境界

### MVPに入れる

- 3ステージ、各458m
- 3レーン左右移動
- ビール回収
- 予告列とビールストリーム
- 固定パターンの組み替え
- 接触時のソフトなペナルティ
- 4段階リザルト

### プレイテスト後に検討

- ビールサーバ: 近くのビールを引き寄せる
- アーロンチュア: 接触を1回だけ防ぐ段ボールシールド
- 日替わり「本日のレギュレーション」
- エンドレスモード
- ベランダなどの追加コース
- やめたろうのWANTEDポスターを集める期間イベント
- ランキング

パワーアップを増やすより、左右移動、視認距離、取得音、
正解後の連続取得の気持ちよさを優先して調整する。

## 7. 実装方針（次フェーズ）

- 見た目は2Dではなく、参考画像に合わせた軽量な3Dランナーを推奨
- Vite + TypeScript + Three.js
- `04_GAME_ASSETS/voxel/models/sobaya.glb` を `public/models/` から相対symlink参照
- 既存の正典ボクセルリグを使い、GLBはコピーも手編集もしない
- プレイヤーのZ位置をほぼ固定し、コースと配置物を手前へ流す
- ビールと障害物はInstancedMeshまたはオブジェクトプールで再利用する
- 3レーンを `x = -2.4 / 0 / 2.4` の固定座標として扱う
- コースパターンに「全レーン閉鎖がない」「反応時間を満たす」自動テストを用意する
- モバイル表示では3レーンとHUDをセーフエリア内に保ち、縦横どちらでも操作可能にする

## 8. 成功判定

最初の試作は次を満たせば成功とする。

1. 説明を読まなくても、5秒以内に左右移動とビール回収を理解できる
2. 45秒を最後まで遊ぶ人の多くが、もう一度すぐ再挑戦できる
3. 正解レーンの連続取得が、通常の1杯取得より明確に気持ちよい
4. 接触しても嫌にならず、次の判断へ戻れる
5. スクリーンショットだけで「窓際族物語のそば屋」と分かる
