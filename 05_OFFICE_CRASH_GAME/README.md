# そば屋のオフィスクラッシュ ～無限フロア大整理～

窓際族のそば屋を操作し、図面にない「備品循環棟」を攻略する
3Dアクションハクスラ＋ローグライトです。

タコ部屋脱走時にできた人型の大穴の先で、謎のレギュレーション管理システムが暴走。
歩き出したオフィス備品を大型ビールジョッキで資材へ戻し、
8つのランダムビルド対応フロアを片付けます。

## ゲーム内容

- 通常戦、エリート戦、15秒クラッシュタイム、窓際族ボス戦を含む全8フロア
- 回転アーロンチュア、ホチキスガニ、キャビネットゴーレム、会議机ムカデなどの暴走備品
- 4Fはプレイ回数に応じて巡回する窓際族メンバー、8Fは大型画面越しのおかやまん
- よーたんのギター音波、おかやまんの画面ビームなど、原典の持ち物と個性に沿った固有攻撃
- ボス戦は平和な模擬戦。勝つと相手は壊れず、星を回して目を回しながら休憩する
- 金の特大ジョッキ、泡盛ビール樽、冷却サーバー、お盆シールド、赤提灯、退社スニーカーの6装備
- 1ランで持てる装備は3種類。同じ装備を重ねると「改」「極」へ進化
- 3枠が埋まった後は所持装備の進化だけが候補に出る、違いが分かりやすい戦利品ドラフト
- 泡の連鎖破壊、凍結砕き、乾杯コンボ、焼き鳥回復、回避攻撃など見た目と挙動が変わるビルド
- 生成した専用ボクセル画像を戦利品カード、HUD、キャラクター頭上の装備表示に使用
- 快速、装甲、余熱、再生の能力を持つエリート備品
- 隊列を組んで押し寄せる大群、撃破ノルマ制、最大4体の同時攻撃制限
- 連続整理で清掃熱を溜め、大量増援が入る12秒間のOFFICE RUSHへ突入
- 「残業」「定時退社」「フライング退社」の3段階から選ぶ退社作戦
- 高難度の必要破壊数は2倍、3倍。定時前にこっそり帰るフライング退社が最高難度
- 難度が上がるほどボスの攻撃頻度と予告範囲が強化され、短い反動時間に攻める回避重視の戦闘へ変化
- 8Fは残業ならおかやまん単独、定時退社ならランダム助っ人1名、フライング退社なら2名が追加参戦
- ボスのセリフは通常通知と別の専用吹き出しへ長めに表示
- ボス攻撃の予告は赤い専用照準へ統一し、発動時はキャラ色の衝撃柱や発光ビームを描画
- 8Fで倒したメンバーは目回し演出の約3秒後、光の輪とともに画面から退場
- 撃破・回避・生ジョッキ取得で補充できるゲージ式必殺技「生ジョッキレール」
- ジョッキは直線貫通するほど巨大化し、終点でオフィス備品ごと大爆発
- 中心線への直撃、複数体の一網打尽、ボス反動中の発動でさらに高ダメージ
- 無強化の通常スマッシュが約10になる表示倍率で敵の頭上へダメージを表示。会心・弱点・MEGA・泡連鎖は色と大きさも変化
- 窓際族ボスはHP半分でENCORE PHASEへ移行し、固有攻撃が追加・強化
- 赤い床の円・ビーム予告を見て、位置取りとダッシュで避ける敵・ボス攻撃。おかやまんは予告後に実体のある大型ビームを発射
- 画面外の敵を自動で中央へ戻す再配置と、画面外の敵を知らせる索敵表示
- モニター、書類、給水機もコンボへ組み込めるオフィス破壊
- Rapierの固定タイムステップ物理で、積み上げた書類箱、回転椅子、ゴミ箱、破片が跳ね、転がり、壁へ衝突
- KootaのECSで物理オブジェクトの生成・寿命・描画同期・上限管理を一括処理
- スマッシュやダッシュで飛ばした備品が敵へ当たる「PHYSICS HIT」と、連続衝突で伸びる「PHYSICS CHAIN」
- PERFECT SMASH、MULTI BREAK、COMBO FREEZE、HPと回復アイテム
- PCとスマートフォンの両方に対応

## 永続記録

SitesのD1データベースを使用し、プレイヤー単位で以下を保存します。

- 自己ベスト、最高到達階、総ラン数、総備品整理数、完全制覇数
- ラン履歴、獲得装備と進化段階、選択した退社難度
- 王冠キャップ
- 20文字までのユーザーネーム（未設定時は「匿名窓際社員」）
- 黄金ビールサーバー、まかないショーケース、秘密の非常口の3つの王冠設備
- 旧「ジョッキ鍛造・最大HP・移動速度」へ使った王冠は初回アクセス時に全額自動払い戻し
- 全プレイヤー集計と、各ユーザーの自己ベストによる上位スコアボード

ブラウザ内ストレージを正本にせず、ゲームデータはサーバー側へ記録します。

## 操作

- PC: `WASD` / 矢印キーで移動、`Space`でスマッシュ、`E`で生ジョッキレール、`Shift`でダッシュ
- スマホ: 左の仮想スティックで移動、右のSMASH / RAIL / DASHボタン
- `P` / `Esc`: 一時停止

## 開発

```bash
npm install
npm run dev
npm test
```

Three.js、Rapier、Koota、React、vinext、Cloudflare D1、Drizzleで構成されています。

描画はThree.js、剛体シミュレーションはRapier、動的な物理オブジェクトの
ライフサイクル管理はKootaへ分担しています。ゲーム本体の既存ロジックを保ったまま、
物理演算とECSを「吹き飛ぶオフィス備品」という遊びへ直結させた構成です。

## 正典3Dモデル

- Web用: `public/models/*.glb`
- 正典モデル: `../04_GAME_ASSETS/voxel/models/*.glb`
- 改変用Blenderマスター: `../04_GAME_ASSETS/voxel/model_source/sobaya_voxel_master.blend`

`public/models/*.glb` は、そば屋と窓際族ボスの正典モデルへの相対symlinkです。
白い仮面と大型ビールジョッキを維持したまま、共通ボクセルキャラクターキットの
歩行・スマッシュアニメーションを使用します。
