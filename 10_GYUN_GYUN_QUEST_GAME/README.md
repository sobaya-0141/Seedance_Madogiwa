# ギュンギュン・クエスト

魔王となったそば屋へ最高の一杯を届ける、ファミコン時代のRPGを思わせる短編2Dゲームです。

## 遊び方

- PC: 矢印キー / WASDで移動、Enter / Space / Zで話す・調べる
- スマホ: 画面下の十字キーとAボタン
- 福ギュン王から500円を受け取り、城下町の道具屋でアイテムを買って洞窟を目指します
- 雑魚敵の窓際見習い・ベテラン窓際は何もしません。様子を見ると、そのうち定時で帰ります

## エンディング条件

- スーパードライ: グッドエンド
- エビス: ギリギリクリア
- その他: ゲームオーバー

## 技術メモ

- Vite + TypeScript、追加ランタイム依存なし
- オープニング動画は `04_GAME_ASSETS/videos/gyun-gyun-quest/opening.mp4` を正典とし、`public/videos/` から相対symlinkで参照
- カットシーンはタイトル画面のユーザー操作直後に音声付き再生し、タップでスキップ可能
- そば屋の白い仮面・大型ビールジョッキ、たこさんの黒いローブ・触手をゲーム内でも維持

## 開発

```bash
npm install
npm run dev
npm run build
```
